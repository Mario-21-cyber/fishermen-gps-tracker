Technology Stack Summary

Component Technology Purpose
Backend server Node.js (built-in http, zero npm dependencies) Receives GPS telemetry, stores data, serves the dashboard API
Frontend HTML5, CSS3, Vanilla JavaScript Map dashboard, alerts, vessel management, sailing records
Map rendering Leaflet.js 1.9.4 + OpenStreetMap tiles Live vessel map, route polylines, geofence circle
Firmware C++ (Arduino framework, PlatformIO) GPS reading and telemetry transmission on the boat
Hardware ESP32 + u-blox NEO-M8N GPS + SIM7600E LTE modem On-board tracking unit
GPS parsing TinyGPSPlus library Parses NMEA sentences from the GPS module
Authentication PBKDF2/bcrypt salted hash + random session tokens Protects the dashboard from unauthorised access
Storage File-based JSON (data/*.json) All persistent data — no database server required
Real-time Server-Sent Events (SSE) Live position and alert push to the browser
Web server nginx (port 80 reverse proxy → Node.js port 3000) Public entry point, gzip, caching, upload size limit
Process manager systemd Auto-restart the server on crash or reboot
Deployment Bash (deploy-droplet.sh) One-command server setup and board flashing
